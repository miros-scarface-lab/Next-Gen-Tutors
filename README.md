Next Gen Tutors

Connecting students with the right tutors.

Next Gen Tutors is a tutoring service website designed to help students
and families discover tutoring support and get in touch with the team.
The platform provides an online presence for the service, making it
easier for visitors to learn about tutoring options and contact Next Gen
Tutors.

Getting Started

Follow these steps to run the project locally after cloning the
repository.

git clone <your-github-repository-url>
cd <repository-folder>

Install dependencies using the package manager configured for the
project. For an npm-based project:

npm install

Start the development server using the script defined in package.json.
For many Vite or Next.js projects, this may be:

npm run dev

Then open the local URL shown in your terminal.

Note: The commands above are a general starting point. Check the
repository's package.json and project structure to confirm the correct
setup commands.

Deployment

The live site is hosted on Vercel.

To deploy your own copy: 1. Push the project to a GitHub repository. 2.
Import the repository into Vercel. 3. Configure any required environment
variables in the Vercel project settings. 4. Deploy and verify the
production URL.
